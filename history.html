The evolution of HTML

A small language for sharing scientific information became a common way to structure content across the web.

The beginning at CERN

In 1989, Tim Berners-Lee proposed a system for connecting information at CERN. By the end of 1990, he had built a browser and web server. Early HTML documentation followed in 1991.

The central idea was hypertext: a document could contain links to other documents. Readers could follow those links instead of searching separately for every related resource.

Early HTML focused on recognizable document parts, including headings, paragraphs, and lists. As the web expanded, developers needed shared rules so pages could work in different browsers.

Major milestones

From early tags to a shared standard

Each stage responded to a growing web: more browsers, richer documents, and eventually web applications.

What changed along the way?

  • Shared rules: standards helped browser makers interpret the same markup consistently.
  • Separate styles: HTML described content while CSS handled its presentation.
  • Richer pages: HTML5 added meaningful sections and native audio and video elements.
  • Continuous updates: the Living Standard replaced the need to wait for another major version number.

A note about XHTML

XHTML uses XML rules, including properly nested elements and quoted attribute values. Fatal XML parsing errors can prevent an XML document from displaying normally. Browser error handling also depends on whether a document is served as XML or as HTML.
