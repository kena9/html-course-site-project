About this project

This educational site is a class project for IT 3203: Web Development. Milestone 1 turns the Assignment 1 HTML research presentation into a website.

The project shows HTML's evolution and its core concepts through linked pages, code examples, and a historical timeline.

Visit the class website →

Skills practiced in this project

  • Organizing research into six linked HTML pages.
  • Using semantic headings, lists, images, and tables.
  • Styling pages with one shared CSS file.
  • Arranging content with Flexbox and Grid.
  • Adding keyboard focus styles and responsive layouts.
  • Documenting the implementation with code comments.

Learning reflection

Semantic HTML elements such as <nav> and <main> give content a clear purpose and help make the pages easier to navigate. CSS Grid organizes content into a layout that can adapt to different screen sizes.
