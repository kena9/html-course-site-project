Research overview

A language built to connect information

HyperText Markup Language (HTML) uses elements to identify headings, paragraphs, links, images, and other content. Browsers interpret this markup to build a web page.

This website adapts my Assignment 1 research into a beginner's guide. It follows HTML's history, explains modern document structure, and introduces concepts that help make websites understandable and accessible.

HTML supplies structure, CSS controls appearance, and JavaScript can add behavior. This project focuses on the first two.
