Sources for the research

The Assignment 1 PowerPoint is the main content. The standards and documentation support the adapted explanations and historical dates.

Historical sources

  1. CERN. The birth of the Web.

    Background on Berners-Lee, CERN, and the first website.

  2. Berners-Lee, T., & Connolly, D. (1995). Hypertext Markup Language – 2.0 (RFC 1866).

    The historical HTML 2.0 specification, published in November 1995.

  3. W3C. (1997). HTML 3.2 Reference Specification.

    Documents the January 1997 Recommendation and its features.

  4. W3C. (1999). HTML 4.01 Specification and Introduction to HTML 4.

    Historical material on structured documents, accessibility, and separation of presentation.

  5. W3C. (2000; revised 2002). XHTML 1.0: The Extensible HyperText Markup Language.

    Explains the reformulation of HTML using XML.

  6. W3C. (2014). HTML5: W3C Recommendation, 28 October 2014.

    The dated HTML5 Recommendation. Use the Living Standard when writing new HTML.

The modern standard

  1. WHATWG. HTML Living Standard, including its history section.

    The continuously maintained specification and its account of HTML's development.

  2. W3C & WHATWG. (2019). Memorandum of Understanding Between W3C and WHATWG.

    The May 28 agreement describing collaboration on HTML and DOM specifications.

Learning resources

  • MDN: Basic HTML syntax

    A beginner guide to elements, attributes, and document structure.

  • MDN: Semantics

    How meaningful elements describe content.

  • MDN: Document Object Model

    How a browser represents a document as objects.

  • MDN: The input element

    Form input types, attributes, and usage guidance.

  • MDN: Popover API

    Native popover behavior, examples, and compatibility information.

  • W3C Nu HTML Checker

    Upload an HTML file to check its markup. Review the CSS with the W3C CSS Validation Service.
