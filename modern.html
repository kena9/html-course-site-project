HTML in the modern web

Modern HTML mixes meaningful document structure with native browser features. Its development continues with the HTML Living Standard.

One language, continuous development

The WHATWG maintains the HTML Living Standard. Its text changes as contributors resolve issues, refine browser behavior, and develop features. Compatibility with existing pages is a central design concern.

The 2019 agreement between W3C and WHATWG established a shared approach to HTML and DOM development. The term HTML5 remains useful when talking about the 2014 milestone, while the Living Standard describes the evolving language.

How the web languages work together

  • HTML: identifies the content and its meaning.
  • CSS: sets colors, typography, spacing, and layout.
  • JavaScript: can respond to actions and change the document.

Document anatomy

A structure the browser can understand

A page has a <head> for metadata and a <body> for its content. A meaningful structure helps both readers and software interpret the page.

  1. <!DOCTYPE html> requests modern standards mode.
  2. <html lang="en"> identifies the document's main language.
  3. <head> contains the page title, character encoding, and stylesheet link.
  4. <body> contains headings, text, images, and page sections.

Features and meaning

What modern HTML makes possible

Semantic page regions

Elements such as <nav>, <main>, and <article> describe content roles. Choose an element for its meaning, then use CSS to control how it looks.

Native multimedia

The <audio> and <video> elements support media playback in the browser. Video captions and text alternatives help make media accessible.

More useful forms

Input types such as email, date, and number give browsers information about expected values. Labels explain the purpose of each field.

Native interactions

Features such as the Popover API can support basic show-and-hide interactions through HTML attributes. Browser support and accessibility still need checking for the feature and intended use.

HTML belongs to a larger platform

The research also covers browser storage, Service Workers, and Web Components. These involve web APIs and often JavaScript. They extend what web applications can do, while HTML continues to describe the content.
