03 · Key concepts

Seven ideas behind every page

These concepts connect HTML's history to the markups. Each definition includes a small example.

Definitions and examples

CONCEPT 01

Markup language

A markup language describes the structure and meaning of content. HTML marks text as a heading, paragraph, list item, or another document part.

<h1>HTML history</h1>

This marks the text as a top-level heading.

CONCEPT 02

Elements and tags

An element is a building block of a page. Many elements have a start tag, content, and an end tag. Void elements, such as <img>, do not have an end tag.

<p>A short paragraph.</p>

The complete paragraph is an element; <p> and </p> are its tags.

CONCEPT 03

Attributes

Attributes provide extra information in a start tag. For example, href sets a link destination and lang identifies a language.

<html lang="en">

Here, lang is the attribute name and en is its value.

CONCEPT 04

Hyperlinks

A hyperlink connects a page to another resource or to a location within a page. The anchor element makes the connection, and descriptive link text tells readers where it leads.

<a href="history.html">HTML history</a>

This relative link opens another page in the same folder.

CONCEPT 05

Document Object Model (DOM)

The DOM represents a document as a tree of objects. The browser builds this tree from the markup. JavaScript can use the DOM to read or change page content.

<main><p>Hello!</p></main>

The paragraph is a child of the main element in the document tree.

CONCEPT 06

Semantic HTML

Semantic elements communicate the purpose of content. A <nav> contains navigation links, while <main> identifies the page's main content.

<nav aria-label="Main navigation">...</nav>

The element names the region; the label distinguishes its purpose.

CONCEPT 07

Accessibility

Accessible pages help people use content with different abilities and tools. Meaningful headings, keyboard access, descriptive links, and appropriate image alternatives all contribute.

<img src="photo.jpg" alt="A web server at CERN">

Alternative text describes an informative image. Decorative images use an empty alt="" attribute. This snippet is illustrative.
